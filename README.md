# College Pick'em V7.0.27

Season standings rank by record, not points.

Changes:
- Season Leaderboard, Season Rank (on the Welcome card), and rank-movement arrows now sort by ATS record first (most wins, then fewest losses), with total points only used as a tiebreaker when two players have the exact same win-loss record.
- Weekly rank, the weekly champion, and the Game of the Week tiebreak are unchanged and still use the point-weighted system (correct pick value + tiebreak score) — that scoring only ever applied to deciding each individual week, not the season.
- "Season Points" still displays on the Welcome card as an informational stat; it's just no longer what determines Season Rank.
- Includes all V7.0.26 functionality (banner blend, This Week above Season on the summary card).

No Firestore rules changes are required.
